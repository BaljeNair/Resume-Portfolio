CASE STUDY 01 · ENDPOINT ENGINEERING · NCS

A baseline built
to scale.

A secure, repeatable Windows 10 deployment template for large-scale endpoint refresh work.

EnvironmentWindows enterpriseFocusGPO · Imaging · SecurityResultStandard deployment template

The situation

Every refresh needed a dependable starting point.

Large-scale refresh work becomes harder when every device begins from a different baseline. The build needed to be repeatable for engineers while meeting the organisation’s security and operational requirements.

My contribution

Harden the image once. Make every deployment clearer.

  • Built a Windows 10 enterprise baseline image from scratch.
  • Configured Group Policy Objects for security policies and password standards.
  • Restricted removable media and disabled unnecessary services.
  • Created a deployment foundation that other refresh work could reuse.

Tools and decisions

Security controls that remain practical for the delivery team.

Windows 10Group PolicyEndpoint imagingSecurity baselineRefresh delivery

The focus was not adding complexity for its own sake. It was making the secure path the repeatable path, so the next engineer could deploy with fewer decisions to recreate.

Outcome

The image was adopted as the organisation’s standard deployment template.

That outcome turned one piece of engineering work into a reusable operational asset for future endpoint deployments.

CASE STUDY 01 · ENDPOINT ENGINEERING · NCS

A baseline built
to scale.

A one-machine Windows 10 Enterprise baseline mini-project built from scratch with Group Policy and a fast USB imaging loop.

EnvironmentWindows 10 EnterpriseFocusGPO · USB imagingTypePersonal engineering mini-project

The situation

Start with a vanilla image. Learn what a proper baseline needs.

At NCS I got curious about how a proper enterprise baseline should work, so I built one myself as a mini-project. The setup was deliberately small: one machine, a vanilla Windows 10 Enterprise image, and a clean process that I could test and rebuild quickly.

My contribution

Test, break, and rebuild the secure path.

  • Built the baseline from scratch on one machine.
  • Configured Group Policy for password policy and removable-media controls.
  • Disabled unnecessary services and tested the resulting configuration.
  • Used a USB drive with the vanilla image instead of waiting on network imaging.

Tools and decisions

A faster loop made the learning more practical.

Windows 10 EnterpriseGroup PolicyUSB imagingPassword policyRemovable media

Using a USB drive was noticeably faster for this small experiment. It let me test and rebuild quickly without waiting for network imaging, while making each security and configuration decision easier to understand.

What it shows

I do not just follow a build guide. I test until I understand the baseline.

This project shows a hands-on approach to endpoint engineering: build from a vanilla starting point, verify the controls, break the assumptions, and rebuild the process until it is clear.
